# LeaderFlow website

The [leaderflow.org](https://leaderflow.org) website as plain HTML, CSS and JavaScript. There are no frameworks, no build step and no runtime dependencies. Copy on the pages is taken word for word from the live site, except for the approved Phase 1 changes listed in `review/plan/06-build-log.md`.

## Layout

```
site/                 everything that gets published (the host's output directory is "site")
  index.html          one folder per page, mirroring the old site's URLs
  about-us/  become-a-sponsor/  connect-with-us/  flowcilitators/...  leaderflow-development-program/...
  404.html            served for unknown URLs (uses root-relative links, /...)
  donate/             the single place the donation link lives (see below)
  robots.txt  sitemap.xml  favicon.ico  apple-touch-icon.png
  assets/css/site.css all styles (tokens and the APPLICATIONS SWITCH at the top)
  assets/js/site.js   menu, dropdowns, video facades, tabs, form validation, reveal
  assets/fonts/       self-hosted, trimmed Fraunces + Inter (WOFF2) and their OFL licences
  assets/img/         WebP images (grads/ are generated, see "Images")
source-images/        originals for generated images (not published)
tools/                developer scripts (not published)
review/               internal review notes (never published)
```

Everything outside `site/` is never deployed. Don't put internal files inside `site/`.

## Run locally

```sh
npx serve site
# or
python -m http.server 8000 -d site
```

Then open http://localhost:3000 (serve) or http://localhost:8000 (Python). Pages use relative links, so they also work from a sub-path. The 404 page uses root-relative links because the host serves it at any URL.

## Everyday changes

**Open or close applications.** Every page that mentions applications (Home, Program, Application Process, Application Form, FAQ) contains both an "open" and a "closed" version, marked `apps-open` and `apps-closed`. One line near the top of `site/assets/css/site.css`, under `APPLICATIONS SWITCH`, decides which one shows:

```css
.apps-open { display: none !important; }    /* closed (current) */
.apps-closed { display: none !important; }  /* open */
```

Before opening:
1. Search `site/` for `TBC` and replace every placeholder (year, opening date, closing date and time) with the real dates. They appear on Home, Program, Application Process, Application Form and FAQ, and must match everywhere.
2. Make sure the application form is connected (its `data-endpoint` is set; see `review/plan/07-forms-to-monday-plan.md`). The form is its own step-by-step page, `/leaderflow-development-program/application-form/apply/` (the Application Form page's "Start your application" button opens it), and is generated by `tools/application-form/build.py`: edit the questions there and run `python tools/application-form/build.py site`.

**Preview before opening.** Add `?preview=open` to any page address (for example `/leaderflow-development-program/application-form/apply/?preview=open`) to see the "applications open" versions, including the application form, while applications are still closed. A small yellow flag shows you are in preview.

**Donate link.** Every Donate button links to `/donate/`. That page forwards to the real donation URL, which is written in one file: `site/donate/index.html` (the two lines marked `DONATE-URL`). Change it there only.

**Newsletter.** "Get notified" and "Subscribe" link to Mailchimp's hosted form, `https://eepurl.com/ivZ0H6`.

**Footer year.** "© 2026" is plain text in every page footer. Update it with a find-and-replace across `site/`.

## Forms

The Contact form (home page and Connect page) and the Become a Flowcilitator form are front end only for now:

- They validate in the browser (required fields, email, phone, lengths) and show the errors next to each field.
- They contain a hidden honeypot field named `website`. Real visitors never fill it in.
- There is a marked `data-turnstile-slot` where the Cloudflare Turnstile widget will go, with notes in `site.js`.
- `data-endpoint` is empty, so submitting shows "form submissions are not connected yet". When the Pages Function exists, set `data-endpoint` to `/api/contact` or `/api/flowcilitator`. Without JavaScript, the forms post to their `action` URL (the same paths).

The server side (Pages Function, Turnstile check, Google Sheet and email) is not built yet. It must check every field again: the browser checks are only for convenience. See `review/plan/03-security-brief.md` section D.

## Fonts

Fraunces and Inter are self-hosted and trimmed to the weights and characters the CSS uses (about 134 KB on the home page, instead of about 312 KB from Google Fonts). To rebuild them, for example after using a new weight, see the notes at the top of `tools/build-fonts.sh`. It needs Python with `fonttools` and `brotli` in a throwaway virtual environment, plus the source TTFs from github.com/google/fonts, downloaded into their own folder.

## Images

- **Graduates:** put the original photo in `source-images/grads/` (named `year-city-first-last.webp`), run `node tools/images.mjs grads`, then add the person to the graduates page. Copy an existing entry so you get the `srcset` and `sizes` attributes. The script makes 4:5 crops at 240, 360 and 480 px wide. It needs `cwebp` and `dwebp` (libwebp) on your PATH.
- **Never overwrite a published image with different content.** Use a new file name, because images may be cached for a long time.
- **Icons:** `node tools/make-icons.mjs` regenerates `favicon.ico` and `apple-touch-icon.png` from `assets/img/brand/favicon.svg`.

## Checks before publishing

```sh
node tools/check-links.mjs                                         # every internal link, image and anchor resolves
python -m http.server 8123 -d site                                 # in another terminal
node tools/check-pages.mjs http://127.0.0.1:8123 .check-out        # console errors, failed requests, weights, screenshots
```

`check-pages.mjs` drives an installed Edge or Chrome over the DevTools protocol and needs nothing installed from npm (Node 22 or newer). `.check-out/` is scratch output; don't commit it.

## Notes

- Videos load only when clicked. The promo MP4 still streams from the old WordPress host and must move to LeaderFlow's Vimeo before launch (marked `TODO(M7, D6)`).
- There are no inline `style` attributes or inline scripts, so a strict Content-Security-Policy works without `'unsafe-inline'`.
- Motion respects `prefers-reduced-motion`. The base CSS is the finished state, and animation is layered on top.
- `site/.nojekyll` only matters for GitHub Pages. It can be deleted once the site is on Cloudflare Pages.
